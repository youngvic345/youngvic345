# Product configurator

**React · TypeScript · Vite · Netlify Functions · Odoo website embed**

A visual, step-by-step configurator so a bakery's customers can design a cake and request a quote, built to sit inside an Odoo website.

## What it does

- A guided wizard with separate steps for coating and toppings and for filling layers, with a live visual preview.
- Fillings and toppings are image cards (modern image formats with fallbacks), not dropdowns, and toppings are toggle buttons with thumbnails.
- Quote requests are sent through a serverless function.
- A lightweight embed build, plus a demo page and a simulator so the embed can be tested before it goes on the real site.
- Integration guides for Odoo's website builder (HTML block with an iframe), a deployment guide, and a GitHub Pages workflow.

## Process

Three iterations: a Google AI Studio scaffold, a first working version, and a refined version with the card-based UI and quote flow.
